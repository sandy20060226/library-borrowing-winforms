# 圖書借閱程式
使用 C# 與 Windows Forms 製作的個人課堂作業，練習視窗介面操作、借閱資料輸入與日期範圍限制。

## 使用技術
- C#(Windows Forms)
- 使用Visual Studio撰寫

## 主要功能
- 顯示書籍資訊。
- 借閱時填寫讀者姓名與電話。
- 設定借閱期限為一個月，限制讀者只能選擇期限內的歸還日期。
- 借閱成功後，顯示借閱資料與「祝你有個好的閱讀體驗」提示。

## 操作流程
1. 查看書籍並進入借閱流程。
2. 填寫姓名與電話。
3. 選擇一個月期限內的歸還日期。
4. 確認借閱，查看借閱結果。

## 個人負責內容
本專案為個人作業，視窗介面設計與程式撰寫皆由本人完成。

## 執行方式
1. 下載或複製本儲存庫。
2. 使用支援 .NET Framework 4.7.2 的 Visual Studio 開啟 `WindowsFormsApp2.sln`，並確認已安裝「.NET 桌面開發」工作負載。
3. 按下 F5 執行程式。

## 目前限制
- 借閱資料僅於本次執行期間顯示，關閉程式後不會保留。
- 尚未提供借閱紀錄的永久儲存與查詢功能。
